# noderings_credit_balance (Data Source)

The organization's prepaid credit wallet, which pays for usage-billed (hourly) resources. Use it in a `check` block or a precondition to stop before ordering more than the credit covers.

## Example Usage

```terraform
data "noderings_credit_balance" "this" {}

check "enough_credit" {
  assert {
    condition     = data.noderings_credit_balance.this.available >= 20 && !data.noderings_credit_balance.this.frozen
    error_message = "Top up credits before adding more hourly virtual machines."
  }
}
```

## Schema

### Read-Only

- `available` (Number) Credit that can pay for new resources: the balance minus what is reserved.
- `balance` (Number) Total credit.
- `currency` (String) Currency of the amounts, for example `USD`.
- `frozen` (Boolean) Whether the wallet is frozen. A frozen wallet cannot pay for new usage-billed resources.
- `frozen_reason` (String) Why the wallet is frozen, if it is.
- `promotional` (Number) Promotional credit included in the balance.
- `promotional_expiring_soon` (Number) Promotional credit that expires soon.
- `reserved` (Number) Credit held for running usage-billed resources.

# noderings_marketplace_addon (Data Source)

Finds an add-on (backups or an additional IP) for a virtual machine or a provider. Add-ons that are not compatible with the VM's plan code are skipped. Fails unless exactly one add-on matches; set `code` to choose.

## Example Usage

```terraform
# When the provider sells several backup add-ons, choose one with code.
data "noderings_marketplace_addon" "backup" {
  type               = "backup"
  code               = "DAILY-BACKUP"
  virtual_machine_id = noderings_virtual_machine.web.id
}

output "backup_price" {
  value = data.noderings_marketplace_addon.backup.prices
}
```

### Optional

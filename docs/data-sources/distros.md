# noderings_distros (Data Source)

Operating systems that virtual machines can be created with. Whether a given provider offers one is only known when a VM is created in its region.

## Example Usage

```terraform
data "noderings_distros" "all" {}

output "distros" {
  value = data.noderings_distros.all.distros[*].distro
}
```

# noderings_permissions (Data Source)

Lists permissions, optionally only those of some services. Use `ids` as a role's `permission_ids` to grant everything a service offers.

## Example Usage

```terraform
data "noderings_permissions" "dns" {
  services = ["DnsZoneService", "DnsRecordService"]
}

output "dns_permissions" {
  value = [for p in data.noderings_permissions.dns.permissions : p.name]
}
```

### Optional

- `services` (List of String) Service names, for example `["DnsZoneService", "DnsRecordService"]` (case-insensitive). Every service must match at least one permission. Omit to list every permission.

# noderings_marketplace_plan_codes (Data Source)

Plan codes for sale on the marketplace, sorted by code and billing type. A plan code (for example `SC-GC-2C-4G-80`: general compute, 2 vCPUs, 4 GB memory, 80 GB disk) means the same size at every provider.

## Example Usage

```terraform
data "noderings_marketplace_plan_codes" "frankfurt" {
  country      = "Germany"
  city         = "Frankfurt"
  billing_type = "usage"
}

output "plan_codes" {
  value = data.noderings_marketplace_plan_codes.frankfurt.plan_codes[*].plan_code
}
```

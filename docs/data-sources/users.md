# noderings_users (Data Source)

Lists the organization's users, or looks some up by email, so group memberships and role assignments can be written with email addresses.

## Example Usage

```terraform
data "noderings_users" "all" {}

data "noderings_users" "admins" {
  emails = ["alice@example.com", "bob@example.com"]
}

output "admin_ids" {
  value = data.noderings_users.admins.ids
}

output "alice" {
  value = data.noderings_users.all.ids_by_email["alice@example.com"]
}
```

### Optional

- `emails` (List of String) Email addresses to look up (case-insensitive). Every address must belong to a user of the organization. `ids` follows the same order. Omit to list every user.

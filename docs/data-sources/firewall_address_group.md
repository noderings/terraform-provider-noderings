# noderings_firewall_address_group (Data Source)

Looks up a firewall address group by ID or exact name. This includes the address groups the platform creates for each virtual machine, named like its hostname.

## Example Usage

```terraform
data "noderings_firewall_address_group" "office" {
  name = "office-networks"
}
```

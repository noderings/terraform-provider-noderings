# noderings_storefront (Data Source)

A provider's public storefront page. Use `noderings_marketplace_provider` for its catalog: plans shown on a storefront are not checked for availability.

## Example Usage

```terraform
data "noderings_storefront" "acme" {
  slug = "acme-hosting"
}

output "tagline" {
  value = data.noderings_storefront.acme.tagline
}
```

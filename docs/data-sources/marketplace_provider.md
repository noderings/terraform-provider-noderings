# noderings_marketplace_provider (Data Source)

Looks up a hosting provider by ID or storefront slug, with its full catalog: every plan with its regions and prices.

## Example Usage

```terraform
data "noderings_marketplace_provider" "acme" {
  storefront_slug = "acme-hosting"
}

output "plan_codes" {
  value = distinct(data.noderings_marketplace_provider.acme.plans[*].plan_code)
}
```

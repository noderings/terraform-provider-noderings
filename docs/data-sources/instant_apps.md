# noderings_instant_apps (Data Source)

Lists Instant Apps (one-click application images), with the variables each accepts in `instant_app_variables` of `noderings_virtual_machine`.

## Example Usage

```terraform
data "noderings_instant_apps" "cms" {
  categories = ["cms"]
}

# The variables each app accepts in instant_app_variables.
output "apps" {
  value = { for a in data.noderings_instant_apps.cms.instant_apps : a.slug => a.variables[*].name }
}
```

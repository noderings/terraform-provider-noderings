# noderings_permission (Data Source)

Looks up one permission, which allows one API method, by its service and method name. Permission IDs differ between deployments, so roles should look them up rather than hard-code them.

## Example Usage

```terraform
data "noderings_permission" "create_zone" {
  name = "DnsZoneService::CreateDnsZone"
}

data "noderings_permission" "list_zones" {
  service = "DnsZoneService"
  method  = "ListDnsZones"
}

resource "noderings_role" "zone_creator" {
  name = "zone-creator"
  permission_ids = [
    data.noderings_permission.create_zone.id,
    data.noderings_permission.list_zones.id,
  ]
}
```

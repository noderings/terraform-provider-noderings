# noderings_virtual_machine_snapshot (Resource)

**Experimental.** A snapshot of a virtual machine's disk. The NodeRings console does not show snapshots yet, so this resource may change in a later release.

Only platforms with the `snapshots` capability (Proxmox) support snapshots. Reinstalling or deleting the VM deletes its snapshots. Restoring a snapshot is not managed by Terraform.

## Example Usage

```terraform
resource "noderings_virtual_machine_snapshot" "before_upgrade" {
  virtual_machine_id = noderings_virtual_machine.web.id
  description        = "Before the 2.0 upgrade"
}
```

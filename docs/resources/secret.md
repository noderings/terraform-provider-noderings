# noderings_secret (Resource)

An organization secret. The API never returns a secret's value, so Terraform cannot detect changes made to it outside Terraform. The value is stored in the Terraform state; protect the state accordingly.

## Example Usage

```terraform
variable "registry_password" {
  type      = string
  sensitive = true
}

resource "noderings_secret" "registry_password" {
  key   = "registry_password"
  value = var.registry_password
}
```

### Required

# noderings_firewall_ruleset_attachment (Resource)

Attaches a firewall ruleset to a virtual machine. A VM has at most one ruleset; use one attachment per VM.

Only platforms with the `guest_firewall` capability (Proxmox) support firewalls. Rule changes reach the VM within about a minute; the API does not report when they are applied.

The platform marks the VM as running when a ruleset is attached or detached. If the VM was stopped, this resource stops it again afterwards, so `power_state` on `noderings_virtual_machine` does not drift.

## Example Usage

```terraform
resource "noderings_firewall_ruleset_attachment" "web" {
  virtual_machine_id = noderings_virtual_machine.web.id
  ruleset_id         = noderings_firewall_ruleset.web.id
}
```

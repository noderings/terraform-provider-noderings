# noderings_dns_zone_dnssec (Resource)

Signs a zone with DNSSEC. Add the `ds` value as a DS record at your registrar; the zone becomes `signed_active` once NodeRings sees it there.

## Example Usage

```terraform
resource "noderings_dns_zone_dnssec" "example" {
  zone_id = noderings_dns_zone.example.id
}

# Add this as a DS record at your registrar.
output "ds_record" {
  value = noderings_dns_zone_dnssec.example.ds
}
```

## Schema

### Required

- `zone_id` (String) Zone ID.

### Optional

- `force_destroy` (Boolean) Turn DNSSEC off even while the registrar still has the DS record. That breaks resolution for validating resolvers until the DS is removed. Defaults to `false`.

### Read-Only

- `algorithm` (String) Signing algorithm.
- `digest_type` (Number) DS digest type.
- `dnskey` (String) Public signing key.
- `ds` (String) DS record to add at the registrar, as `<key tag> <algorithm> <digest type> <digest>`.
- `ds_at_parent` (Boolean) Whether the parent zone has the DS record.
- `id` (String) Same as `zone_id`.
- `key_tag` (Number) Key tag.
- `mode` (String) `signed_ds_pending` until the DS is seen at the parent, then `signed_active`.

# noderings_virtual_machine_additional_ip (Resource)

One extra IPv4 address for a virtual machine, from the same network as its primary address. A VM can have at most 10.

**Billing:** each address is a paid add-on. VMs on a monthly plan are charged a prorated amount when the address is added. Destroying this resource releases the address immediately; you may not get the same address back.

## Example Usage

```terraform
resource "noderings_virtual_machine_additional_ip" "web" {
  count              = 2
  virtual_machine_id = noderings_virtual_machine.web.id
}

output "extra_ips" {
  value = noderings_virtual_machine_additional_ip.web[*].ip_address
}
```

# noderings_environment_variable (Resource)

An organization environment variable. Its value is not secret: anyone who can read the organization's variables can see it. Use `noderings_secret` for credentials.

## Example Usage

```terraform
resource "noderings_environment_variable" "app_env" {
  key   = "app_env"
  value = "production"
}
```

## Schema

### Required

- `key` (String) Key: lower-case letters, digits and `_`. Unique in the organization. Changing it replaces the variable.
- `value` (String) Value, 1 to 32767 characters. Changing it updates the variable in place.

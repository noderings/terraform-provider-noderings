# noderings_virtual_machine (Resource)

A virtual machine ordered from a provider on the NodeRings marketplace.

**Billing:** creating a VM starts a subscription for its plan. Destroying or replacing it cancels the subscription immediately with **no refund** for prepaid (monthly) plans; usage-billed VMs are charged for the final partial hour.

## Example Usage

```terraform
data "noderings_marketplace_offer" "web" {
  plan_code            = "SC-GC-2C-4G-80"
  country              = "Germany"
  city                 = "Frankfurt"
  billing_type         = "usage"
  require_capabilities = ["guest_firewall"]
}

data "noderings_ssh_key" "me" {
  name = "laptop"
}

resource "noderings_virtual_machine" "web" {
  hostname  = "web-1"
  plan_id   = data.noderings_marketplace_offer.web.plan_id
  region_id = data.noderings_marketplace_offer.web.region_id
  distro    = "ubuntu_24_04"

  ssh_key_ids = [data.noderings_ssh_key.me.id]
  tags        = ["web", "prod"]
  power_state = "running"

  deletion_protection = true

  timeouts {
    create = "20m"
  }
}

output "ip" {
  value = noderings_virtual_machine.web.ipv4
}
```

## Schema

### Required

- `hostname` (String) Hostname. Not unique: several VMs may share one. The platform also creates a firewall address group named after it, so don't name your own address groups after VM hostnames. Changing it **replaces the VM** (a new VM, new IP addresses, a new subscription), or reinstalls it when `reinstall_on_change = true`.
- `plan_id` (String) Plan to order, usually `data.noderings_marketplace_offer.<name>.plan_id`. Changing it **replaces the VM**: there is no resize.
- `region_id` (String) Region of the plan, usually `data.noderings_marketplace_offer.<name>.region_id`. Changing it **replaces the VM**.

### Optional

- `coupon_code` (String) Coupon to apply when ordering. Only used at create; later changes are ignored.
- `deletion_protection` (Boolean) When `true`, Terraform refuses to delete the VM, including for a replacement. Defaults to `false`.
- `distro` (String) Operating system, one of `ubuntu_22_04`, `ubuntu_24_04`, `ubuntu_26_04`, `debian_12`, `debian_13`, `fedora_43`, `fedora_44`, `centos_9`, `centos_10`, `rocky_9`, `rocky_10`, `almalinux_9`, `almalinux_10`. See `data.noderings_distros`. Required unless `instant_app_id` is set; with an Instant App it defaults to the app's distro and must match it if set. Whether a provider has an image for a distro is only known at create. Changing it **replaces the VM** (a new VM, new IP addresses, a new subscription), or reinstalls it when `reinstall_on_change = true`.
- `instant_app_id` (String) Instant App to install, usually `data.noderings_instant_app.<name>.id`. Changing it **replaces the VM** (a new VM, new IP addresses, a new subscription), or reinstalls it when `reinstall_on_change = true`.
- `instant_app_variables` (Map of String, Sensitive) Settings for the Instant App. Unknown names are rejected; see the `variables` of `data.noderings_instant_apps`. The API does not return them, so after import write them in configuration. Changing it **replaces the VM** (a new VM, new IP addresses, a new subscription), or reinstalls it when `reinstall_on_change = true`.
- `password` (String, Sensitive) Root password, at most 255 characters. Stored in the Terraform state. The API does not return it, so after import write it in configuration. Changing it **replaces the VM** (a new VM, new IP addresses, a new subscription), or reinstalls it when `reinstall_on_change = true`.
- `power_state` (String) `running` or `stopped`. Changes in place. If unset, Terraform does not manage the power state and only reports it. This is the requested state; the platform does not report the hypervisor's actual state.
- `reinstall_on_change` (Boolean) When `true`, changes to `hostname`, `distro`, `instant_app_id`, `instant_app_variables`, `ssh_key_ids` or `password` **reinstall** the VM in place instead of replacing it. A reinstall keeps the VM, its IP addresses and subscription, but **wipes the disk, deletes all snapshots and cancels the backup add-on**. Defaults to `false`.
- `ssh_key_ids` (Set of String) IDs of SSH keys (`noderings_ssh_key`) to install. Exactly one of `ssh_key_ids` and `password` is required. The API does not return them, so after import write them in configuration. Changing it **replaces the VM** (a new VM, new IP addresses, a new subscription), or reinstalls it when `reinstall_on_change = true`.
- `tags` (Set of String) Tags. Firewall rules can select VMs by tag. Changes in place. Tags starting with `tf-create-` are reserved.
- `timeouts` (Block, Optional) How long to wait for operations to finish. (see [below for nested schema](#nestedblock--timeouts))

### Read-Only

- `additional_ipv4` (Attributes List) Additional IPv4 addresses. Manage them with `noderings_virtual_machine_additional_ip`. (see [below for nested schema](#nestedatt--additional_ipv4))
- `capabilities` (List of String) Features the platform supports, such as `guest_firewall`, `on_demand_backup` and `snapshots`.
- `compliance_held` (Boolean) Whether the VM is held for a compliance review. A held VM rejects most changes.
- `cpu` (Number) vCPUs.
- `created_at` (String) Creation time (RFC 3339).
- `firewall_ruleset_id` (String) Attached firewall ruleset, empty if none. Manage it with `noderings_firewall_ruleset_attachment`.
- `has_active_backup` (Boolean) Whether the backup add-on is active. Manage it with `noderings_virtual_machine_backup`.
- `id` (String) VM ID.
- `instant_app_slug` (String) Slug of the Instant App installed at create or reinstall, if any.
- `ipv4` (String) Primary IPv4 address. On VirtFusion and SolusVM it can stay empty until the platform assigns one.
- `ipv6` (String) Primary IPv6 address, empty if the region has no IPv6.
- `memory_mib` (Number) Memory in MiB.
- `plan_billing_type` (String) `usage` (hourly), `subscription` (monthly) or `free`.
- `plan_code` (String) Platform plan code, for example `SC-GC-2C-4G-80`.
- `platform_driver` (String) Hypervisor platform: `proxmox`, `virtfusion` or `solusvm`.
- `provider_name` (String) Name of the hosting provider.
- `provider_organization_id` (String) ID of the hosting provider.
- `provisioning_state` (String) Provisioning state: `pending`, `processing`, `applied` (ready) or `failed`.
- `region_city` (String) City of the region.
- `region_country` (String) Country of the region.
- `reinstall_status` (String) State of the last reinstall: `none`, `requested`, `deleting`, `provisioning`, `completed` or `failed`.
- `reinstalled_at` (String) Time of the last completed reinstall (RFC 3339).
- `storage_mib` (Number) Disk size in MiB.

## Import

Import is supported using the following syntax:

```shell
# Import a virtual machine by its ID. The API does not return ssh_key_ids,
# password, instant_app_variables or coupon_code: keep them in the
# configuration. Filling them in after an import does not replace the VM.
terraform import noderings_virtual_machine.web 00000000-0000-0000-0000-000000000000
```

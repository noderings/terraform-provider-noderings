# noderings_game_server_backup (Resource)

A backup of a game server's files. Terraform waits until the backup has finished. Backups count against the plan's `backup_limit`. Changing the server's game deletes all its backups; Terraform then creates this one again. Only the most recent backups (about 20) are listed by the API, so with more backups than that, older ones read as deleted. Restoring a backup is not done through Terraform. The game server must be ready.

## Example Usage

```terraform
resource "noderings_game_server_backup" "before_upgrade" {
  game_server_id = noderings_game_server.survival.id
  name           = "before 1.21 upgrade"
  locked         = true
}
```

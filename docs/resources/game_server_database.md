# noderings_game_server_database (Resource)

A MySQL database for a game server, for example for a plugin. Databases count against the plan's `database_limit`. The password is only returned when the database is created and when it is rotated; Terraform keeps it in state (marked sensitive). The game server must be ready.

## Example Usage

```terraform
resource "noderings_game_server_database" "luckperms" {
  game_server_id = noderings_game_server.survival.id
  name           = "luckperms"

  # Change this value to set a new password, for example monthly.
  rotation_trigger = "2026-11"
}

output "luckperms_jdbc_url" {
  value     = noderings_game_server_database.luckperms.jdbc_url
  sensitive = true
}
```

## Schema

### Required

- `game_server_id` (String) ID of the game server. Changing it replaces the resource.
- `name` (String) Database name: letters, digits, `_` and `-`, up to 48 characters. NodeRings adds a prefix (see `full_name`). Changing it replaces the database.

### Optional

- `remote` (String) Hosts that may connect, in MySQL notation. `%` (the default) allows any host. Changing it replaces the database.
- `rotation_trigger` (String) Any value. Changing it sets a new random password. For example, set it to the current month to rotate monthly.

### Read-Only

- `connections_from` (String) Hosts that may connect, as stored.
- `database_id` (String) Database ID.
- `full_name` (String) Database name as created, with the platform's prefix.
- `host` (String) Database host.
- `id` (String) `<game_server_id>/<object ID>`, also the import ID.
- `jdbc_url` (String, Sensitive) JDBC connection URL, including the password. Known under the same conditions as `password`.
- `password` (String, Sensitive) Password. Only known after create or rotation: after an import it is empty until `rotation_trigger` changes.
- `port` (Number) Database port.
- `username` (String) User name.

## Import

Import is supported using the following syntax:

```shell
# Import a database as <game_server_id>/<database_id>. The password is not
# known after an import until rotation_trigger changes.
terraform import noderings_game_server_database.luckperms 00000000-0000-0000-0000-000000000000/abc123
```

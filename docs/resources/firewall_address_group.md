# noderings_firewall_address_group (Resource)

A named list of CIDRs that firewall rules can use as a source or destination. Changes reach the virtual machines that use the group within about a minute.

Creating a virtual machine creates an address group named exactly like the VM's hostname, and later overwrites its CIDRs. Do not give a managed group the hostname of a virtual machine.

## Example Usage

```terraform
resource "noderings_firewall_address_group" "office" {
  name  = "office-networks"
  cidrs = ["203.0.113.0/24", "2001:db8:10::/48"]
}
```

## Schema

### Required

- `cidrs` (Set of String) IPv4 and IPv6 CIDRs, for example `203.0.113.0/24` or `2001:db8::/48`. The API stores each one as its network address with IPv6 compressed (`192.0.2.5/24` becomes `192.0.2.0/24`); write them that way to match what other tools show. Use `0.0.0.0/0` or `::/0` for every address.
- `name` (String) Name, 1 to 63 characters, unique in the organization. Creating a virtual machine creates an address group named exactly like the VM's hostname, and later overwrites its CIDRs. Do not give a managed group the hostname of a virtual machine.

### Read-Only

- `created_at` (String) Creation time (RFC 3339).
- `id` (String) Address group ID.
- `updated_at` (String) Last update time (RFC 3339).

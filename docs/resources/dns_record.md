# noderings_dns_record (Resource)

All records of one name and type in a zone (an RRset). Use one resource per name and type, with every value in `records`.

## Example Usage

```terraform
resource "noderings_dns_record" "www" {
  zone_id = noderings_dns_zone.example.id
  name    = "www"
  type    = "A"
  ttl     = 300
  records = ["192.0.2.10", "192.0.2.11"]
}

resource "noderings_dns_record" "mx" {
  zone_id = noderings_dns_zone.example.id
  name    = "@"
  type    = "MX"
  ttl     = 3600
  records = ["10 mail.example.com.", "20 backup-mail.example.com."]
}

# TXT values are plain text: no surrounding quotes. Long values are split for you.
resource "noderings_dns_record" "spf" {
  zone_id = noderings_dns_zone.example.id
  name    = "@"
  type    = "TXT"
  ttl     = 3600
  records = ["v=spf1 mx -all"]
}
```

## Schema

### Required

- `name` (String) Owner name relative to the zone, in lower case, for example `www` or `_dmarc`. Use `@` for the zone apex and `*` for a wildcard.
- `records` (Set of String) Record values in presentation format, for example `192.0.2.10`, `10 mail.example.com.` (MX) or `0 issue "letsencrypt.org"` (CAA). Write TXT values as plain text without surrounding quotes; long values are split for you. Hostnames should end with a dot.
- `ttl` (Number) Time to live in seconds, 30 to 86400.
- `type` (String) Record type: A, AAAA, ALIAS, CAA, CERT, CNAME, DNAME, DS, HINFO, HTTPS, LOC, MX, NAPTR, NS, OPENPGPKEY, PTR, RP, SMIMEA, SRV, SSHFP, SVCB, TLSA, TXT.
- `zone_id` (String) Zone ID.

### Optional

- `allow_overwrite` (Boolean) Take over records of this name and type that already exist in the zone. Without it, creating fails if they exist. Defaults to `false`.

### Read-Only

- `id` (String) `<zone_id>/<name>/<type>`.

## Import

Import is supported using the following syntax:

```shell
# Import records as <zone_id>/<name>/<type>. Use @ for the zone apex.
terraform import noderings_dns_record.www 00000000-0000-0000-0000-000000000000/www/A
terraform import noderings_dns_record.mx 00000000-0000-0000-0000-000000000000/@/MX
```

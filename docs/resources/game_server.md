# noderings_game_server (Resource)

A game server ordered from a game-server plan. Creating it places an order that is billed according to the plan; Terraform waits until the game is installed. Destroying a fixed-price server forfeits the rest of the paid period.

## Example Usage

```terraform
# A game-server plan ID, for example from the NodeRings marketplace.
variable "plan_id" {
  type = string
}

data "noderings_game_server_games" "paper" {
  plan_id = var.plan_id
  name    = "Minecraft · Paper"
}

resource "noderings_game_server" "survival" {
  name        = "survival"
  plan_id     = var.plan_id
  template_id = data.noderings_game_server_games.paper.id
  accept_eula = true

  # Only these variables are managed; the others keep their values.
  environment = {
    MINECRAFT_VERSION = "1.21.4"
    MAX_PLAYERS       = "30"
  }

  power_state         = "running"
  deletion_protection = true

  timeouts {
    create = "45m"
  }
}

output "address" {
  value = "${noderings_game_server.survival.primary_ip}:${noderings_game_server.survival.primary_port}"
}
```

## Schema

### Required

- `name` (String) Server name, 1 to 64 characters. Changes in place while the server is ready.
- `plan_id` (String) Game-server plan ID. A server cannot move to another plan, so changing it replaces the server (its files are lost).
- `template_id` (String) Game to install, the `id` of a `noderings_game_server_games` entry. Game IDs are specific to the plan's provider. Changing it replaces the server, unless `allow_destructive_game_change` is `true`.

### Optional

- `accept_eula` (Boolean) Accept the game's end-user licence agreement. Required when the game has one (`noderings_game_server_games.eula`). Only used when the server is created or its game changes. Not read back from the API.
- `allow_destructive_game_change` (Boolean) When `true`, changing `template_id` changes the game in place instead of replacing the server. The server keeps its address, but **all files, schedules and backups are deleted**. Defaults to `false`.
- `deletion_protection` (Boolean) When `true`, Terraform refuses to delete the server. Defaults to `false`.
- `docker_image` (String) Container image the game runs in. Must be one of the game's images (`noderings_game_server_startup.docker_images`). Changes in place.
- `environment` (Map of String) Startup variables, such as the game version or player limit. Only the keys listed here are managed; other variables keep their values. At creation, variables that cannot be edited may only be set to their default. Afterwards only user-editable variables can change. Keys are checked against the game's variables (see `noderings_game_server_games`). A change applies the next time the game starts: restart the server (for example by setting `power_state` to `offline` and back) to use it. Removing a key stops managing it; the server keeps its current value.
- `power_state` (String) `running` or `offline`. When set, Terraform starts or stops the server and waits for it. When not set, it reports the live state. New servers start once installed.
- `region_id` (String) Region to place the server in. Defaults to the region of the node the server is placed on. Changing it replaces the server.
- `timeouts` (Block, Optional) Timeouts for long-running operations. (see [below for nested schema](#nestedblock--timeouts))
- `version_value` (String) Game version to install, at most 64 characters. Only used when the server is created; to change the version later, set the game's version variable in `environment`. Not read back from the API.

### Read-Only

- `allocation_limit` (Number) How many extra ports (allocations) the plan allows, besides the primary one.
- `backup_limit` (Number) How many backups the plan allows.
- `created_at` (String) Creation time (RFC 3339).
- `database_limit` (Number) How many databases the plan allows.
- `game_name` (String) Game, for example `Minecraft`.
- `icon` (String) Game icon name.
- `id` (String) Game server ID.
- `last_error` (String) Why the last install failed, if it did.
- `node_id` (String) Node the server runs on.
- `panel_identifier` (String) Short server identifier shown in support conversations.
- `phase` (String) `pending` while installing, `ready`, `error` (failed after payment; reinstall or change the game) or `failed` (failed before payment; delete it).
- `plan_billing_type` (String) `subscription`, `usage` or `free`.
- `plan_code` (String) Plan code, for example `SC-GS-4C-8G-50`.
- `primary_ip` (String) IP address players connect to.
- `primary_port` (Number) Port players connect to.
- `provider_name` (String) Provider that hosts the server.
- `region_city` (String) Region city.
- `region_country` (String) Region country.
- `variant` (String) Game variant, for example `Paper`.

# noderings_dns_zone (Resource)

A DNS zone hosted on NodeRings. After creating it, point the domain's nameservers at the `nameservers` output at your registrar.

## Example Usage

```terraform
resource "noderings_dns_zone" "example" {
  name                = "example.com"
  deletion_protection = true
}

# Set these nameservers at your registrar.
output "nameservers" {
  value = noderings_dns_zone.example.nameservers
}
```

## Schema

### Required

- `name` (String) Domain name, for example `example.com`. Stored lower-case without a trailing dot. Changing it replaces the zone. A domain can be hosted by only one organization at a time.

### Optional

- `deletion_protection` (Boolean) When `true`, Terraform refuses to delete the zone. Defaults to `false`.
- `force_destroy` (Boolean) Delete the zone even while DNSSEC is active and the parent zone still has the DS record. That breaks resolution for validating resolvers until the DS is removed. Defaults to `false`.

### Read-Only

- `created_at` (String) Creation time (RFC 3339).
- `delegation_ok` (Boolean) Whether the parent zone currently delegates to the NodeRings nameservers.
- `dnssec_mode` (String) `unsigned`, `signed_ds_pending` or `signed_active`. Manage DNSSEC with `noderings_dns_zone_dnssec`.
- `id` (String) Zone ID.
- `nameservers` (List of String) Nameservers to set at the registrar.
- `state` (String) `pending_ns` until the domain is delegated to NodeRings, then `active`.
- `unicast_nameservers` (List of String) Optional additional unicast nameservers.

## Import

Import is supported using the following syntax:

```shell
# Import a DNS zone by its ID.
terraform import noderings_dns_zone.example 00000000-0000-0000-0000-000000000000
```

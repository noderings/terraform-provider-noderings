# noderings_firewall_ruleset (Resource)

A firewall ruleset: a named, ordered list of rules that can be attached to virtual machines. Manage its rules with `noderings_firewall_ruleset_rules`. A new ruleset is empty, and an empty ruleset filters nothing: the default policy is to accept traffic in both directions. Only virtual machines on Proxmox support firewall rulesets.

## Example Usage

```terraform
resource "noderings_firewall_ruleset" "web" {
  name = "web"
}
```

## Schema

### Required

- `name` (String) Name, 1 to 63 characters, unique in the organization.

### Optional

- `force_destroy` (Boolean) Delete the ruleset even while virtual machines use it. The API then detaches it from those virtual machines, and the rules last applied to them may stay in effect until they get another ruleset. With the default `false`, Terraform refuses to delete an attached ruleset; detach it first.

### Read-Only

- `attached_vm_count` (Number) Number of virtual machines the ruleset is attached to.
- `attached_vm_hostnames` (List of String) Hostnames of the virtual machines the ruleset is attached to, sorted.
- `created_at` (String) Creation time (RFC 3339).
- `id` (String) Ruleset ID.
- `rule_count` (Number) Number of rules, ingress and egress together.

## Import

Import is supported using the following syntax:

```shell
# Import a firewall ruleset by its ID.
terraform import noderings_firewall_ruleset.web 00000000-0000-0000-0000-000000000000
```

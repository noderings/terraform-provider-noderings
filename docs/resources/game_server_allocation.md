# noderings_game_server_allocation (Resource)

An extra port (allocation) for a game server, for example a query or voice port. NodeRings picks the IP and port. Extra allocations count against the plan's `allocation_limit`. The server's own primary address is not managed by this resource; read it from `noderings_game_server.primary_ip` and `primary_port`. The game server must be ready.

## Example Usage

```terraform
resource "noderings_game_server_allocation" "query" {
  game_server_id = noderings_game_server.survival.id
  notes          = "query port"
}

output "query_port" {
  value = noderings_game_server_allocation.query.port
}
```

## Schema

### Required

- `game_server_id` (String) ID of the game server. Changing it replaces the resource.

### Optional

- `notes` (String) Free-form notes, for example what the port is for. Changes in place.
- `primary` (Boolean) Set to `true` to make this the server's primary address, the one players connect to. It cannot be set back to `false` directly: make another allocation primary instead. Destroying a primary allocation first makes the server's oldest other allocation primary.

### Read-Only

- `alias` (String) Host name alias for the IP, if any.
- `allocation_id` (Number) Allocation ID.
- `id` (String) `<game_server_id>/<object ID>`, also the import ID.
- `ip` (String) IP address.
- `port` (Number) Port.

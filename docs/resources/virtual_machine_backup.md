# noderings_virtual_machine_backup (Resource)

Turns on the paid backup add-on for a virtual machine. The platform then takes backups on its schedule, starting with one right away; list them with `data.noderings_virtual_machine_backups`.

Only platforms with the `on_demand_backup` capability (Proxmox) support backups.

**Billing:** the add-on is charged on the VM's subscription. Destroying this resource cancels the add-on immediately and **deletes all of the VM's backups**. Reinstalling the VM also cancels it.

If the add-on is already active when this resource is created, it is adopted without enabling it again.

## Example Usage

```terraform
data "noderings_marketplace_addon" "backup" {
  type               = "backup"
  virtual_machine_id = noderings_virtual_machine.web.id
}

resource "noderings_virtual_machine_backup" "web" {
  virtual_machine_id = noderings_virtual_machine.web.id
  addon_id           = data.noderings_marketplace_addon.backup.id
}
```

## Schema

### Required

- `addon_id` (String) Backup add-on, usually `data.noderings_marketplace_addon.<name>.id`. Changing it switches add-on in place; the old one is cancelled.
- `virtual_machine_id` (String) ID of the virtual machine. Changing it replaces this resource.

### Read-Only

- `addon_status` (String) Add-on status, `active` while backups are on.
- `addon_subscription_id` (String) ID of the add-on subscription.
- `id` (String) Same as `virtual_machine_id`.

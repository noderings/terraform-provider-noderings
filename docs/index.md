# NodeRings Provider

[NodeRings](https://noderings.com) is a marketplace for infrastructure from independent hosting providers. This provider manages: virtual machines and their add-ons, firewalls, game servers, hosted DNS, SSH keys and access control, plus lookups of marketplace offers, the catalog and billing.

## Example Usage

```terraform
terraform {
  required_providers {
    noderings = {
      source = "noderings/noderings"
    }
  }
}

# The token is read from NODERINGS_TOKEN when not set here.
provider "noderings" {}
```

## Authentication

The provider authenticates with a NodeRings **service-account token**:

1. In the NodeRings console, open **Organization > Access Control > Service accounts** and create a service account.
2. Give it a role that covers the resources you manage. For example, DNS needs the `DnsZoneService`, `DnsRecordService` and `DnssecService` permissions, and SSH keys need `SSHKeyService`. The `noderings_permissions` data source and `noderings_role` resource can build such a role.
3. Generate a token and store it as a secret. It is shown only once.
4. Pass it to Terraform with the `NODERINGS_TOKEN` environment variable (recommended) or the `token` argument.

A service-account token belongs to one organization. To manage several organizations, use one provider block per organization with an `alias`:

```terraform
provider "noderings" {
  alias = "shop"
  token = var.shop_token
}

provider "noderings" {
  alias = "staging"
  token = var.staging_token
}
```

## Billing

Creating a virtual machine or game server on a paid plan charges the organization's saved payment method or prepaid credits. Destroying one cancels its subscription immediately, without a refund for fixed-price plans. Use `deletion_protection` on resources you do not want Terraform to remove.

## Rate limits

The NodeRings API allows about 2 requests per second for each API operation. The provider limits itself to that rate by default (`requests_per_second`) and retries rate-limited requests (`max_retries`). Requests that hit a plan quota are not retried; the error shows the quota and its current usage.

## Schema

### Optional

- `endpoint` (String) API base URL. Defaults to `https://api.noderings.com`. Can also be set with `NODERINGS_API_URL`.
- `http_timeout` (String) Timeout for a single HTTP request, as a duration such as `60s`. Defaults to `60s`.
- `max_retries` (Number) How many times to retry rate-limited and transient failures. Defaults to `25`.
- `organization_id` (String) Organization to act in, sent as `X-Organization-ID`. Defaults to the token's organization. Can also be set with `NODERINGS_ORGANIZATION_ID`.
- `requests_per_second` (Number) Client-side limit on requests per second for each API operation. Defaults to `2`, the API's own limit. Set `0` to disable.
- `skip_organization_check` (Boolean) Skip checking the token and organization when the provider is configured. Defaults to `false`.
- `token` (String, Sensitive) Service-account token. Can also be set with `NODERINGS_TOKEN` (or `NODERINGS_API_TOKEN`, `NR_API_TOKEN`).
